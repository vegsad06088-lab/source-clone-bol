## 🎓 What to Include in Every Doc

### For Features ✨
- [ ] What problem does it solve?
- [ ] Why is it important?
- [ ] How does it work? (business logic)
- [ ] What files are involved?
- [ ] What components/functions?
- [ ] How does it connect to other systems?
- [ ] How do users interact with it?
- [ ] How to configure it?
- [ ] Common issues & fixes?
- [ ] How to test it?

### For Pages 📄
- [ ] What is this page for?
- [ ] What is the URL?
- [ ] What business purpose does it serve?
- [ ] What components does it use?
- [ ] How does data flow through it?
- [ ] What features does it have?
- [ ] What translations are needed?
- [ ] Is it mobile responsive?
- [ ] How to test it?

## ❓ Common Questions

**Q: Do I need to document everything?**  
A: Document features and pages. Not individual lines of code.

**Q: When should I write docs?**  
A: As you code, not after. Makes it part of your workflow.

**Q: Can I modify templates?**  
A: Absolutely! Templates are just starting points.

**Q: Where do I put docs?**  
A: In `docs/` folder, organized by type (FEATURES, PAGES, SYSTEMS).

**Q: Should docs be in Git?**  
A: Yes! Commit them with your code.
